## 潮流工具

### Memmy

[Memmy](https://memmy.bot/) 是我最近在试用的一款跨 Agent 记忆工具。它会定时或手动把本地各个 Harness 工具的消息转化成统一格式，进行分级存储，并提供对应的 skill，让任一 Harness 都可以消费全局记忆。

但它的架构里不只有 Memory，还包含 Agent Runtime、CLI / 桌面端应用、消息网关（可以接入不同的 Channels）、外部工具托管等部分。GitHub 目前有 1.9k star，我觉得它适合作为研究 Memory 的入门。这周我在借助 Sitor 阅读它的架构和源码，计划产出一篇微信公众号文章。

![Memmy 架构概览](/weekly/vol-01/memmy-overview.png)

### cap.so

[cap.so](https://cap.so/home) 是我最近下载的一款开源录屏工具。我计划开始尝试学习博主 Oil 欧呦，自己录一些讲技术的短视频，起步还是有些简单。

它有即时模式、工作室模式（录完之后手动编辑）和截图模式。以前看别人视频时觉得很酷炫的局部放大效果，几乎不用额外做什么操作，原生就可以做到。接下来关键的还是行动起来，和做公众号一起。

下面是一个博主做的录屏工具全面评测网站，有非常多的选择可供参考：[recorder.select](https://recorder.select/)。

这周火出圈的一篇文章：[《我不得不把才华埋葬在昨天》](https://mp.weixin.qq.com/s/zk0KxuLzhmMJ4LPYW_OHMA?click_id=1007949101)。

作者是 DeepSeek Kernel 工程师、北大毕业的刘胜屿。写算子出身的他，现在也眼睁睁地看着 AI 越来越会写算子，甚至再发展下去可能要超过他。而真到了那个阶段，他不得不从享受写算子本身，转身变成“机甲驾驶员”。文章也表达了对未来社会一些偏悲观的感受。

我虽然不算是什么走在时代前沿的科技人员，但是作为程序员，我现在觉得比较好的一种理想状态是：多去参与和体验生活，多结交有意思的人；有了灵感就用 AI 工具去 build，想学源码就学源码，想手写代码就手写代码。不要管那么多意义不意义，成果多分享，尝试打造自己的作品集和 IP，多睡觉，其他一切顺其自然。

### 把东西放在正确的位置

近一段时间突然悟出了对我生活改变挺大的一句话，叫：“把东西放在正确的位置。”

这句话非常简单，但我现在把它作为时常挂在嘴边的一句口诀，因为它帮助我解决了生活秩序上的问题。

比如说，当用完了一件生活上的物品，如果我们下意识地去想一想：“此刻，它是不是在正确的位置？”如果我们意识到了这一点，那么就可以在当下很轻松地把这个东西放到属于它的正确位置上。

更具体的例子，比如说我之前很喜欢把用完的东西随手丢在茶几上，然后茶几上的东西就会越堆越多。隔一段时间，我就要带着一种排斥的心理，开始进行“治理”。同样的场景还有洗手台、马桶、浴室、地面、书桌等等。

所以生活就是一直处在有序到无序、再到有序（所谓熵增到熵减到熵增）的循环。而中间我觉得最破坏幸福感的，就是看到无序但却懒于治理的那一阶段。

但是自从把这句话根植在脑海里以后，每次都会下意识地去想一想，它是不是在正确的位置上，随之生活就干净整洁了很多。它可以把不断膨胀的无序状态掐死在摇篮里。

今天突然想记录一下这个感悟的原因在于，我觉得它不仅仅适用于物品，也适用于时间，包括情感等等无形的东西。比如说：“在这个时间点里，做这样一件事情，它到底是不是对的？”如果不对，那就不要去做它，而应该在正确的时间段里做正确的事情。

希望我们都能很好地对抗生活中的无序，让自己掌控更多的幸福感。
