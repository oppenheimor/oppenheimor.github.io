ColaMD 是一款免费、开源的 Markdown 编辑器，面向日常写作与 AI Agent 协作，支持 macOS、Windows 和 Linux。

支持所见即所得编辑，并实时同步 Claude Code、Cursor、Codex 等 Agent 对本地文件的修改；同目录下的新 Markdown 文件也会自动出现在文件列表中。

提供源码模式、任务列表、LaTeX 公式、Mermaid 图表、多种主题，以及 PDF 和独立 HTML 导出。

来源：[ColaMD 官网](https://colamd.com/)。
